# Техническое задание

## Проект: робот-паук «Harnet» на базе ESP32

---

## 1. Общие сведения

### 1.1 Цель проекта

Целью проекта является модернизация существующего робота-паука «Аркадий».
в текущей версии реализованного на платформе Arduino с управлением через
текстовые команды по Serial-интерфейсу (репозиторий `arkadiy-core`).
Репозиторий: https://github.com/VxDxK/arkadiy-core

В рамках проекта планируется:

1. **Перенос платформы** — перевод прошивки с Arduino на ESP32 (замена
   аппаратной базы и адаптация кода: библиотека сервоприводов, распиновка,
   питание).
2. **Интерфейс ввода команд** — замена текстового ввода через Serial-порт
   на более удобный способ управления (уточняется: Wi-Fi веб-интерфейс /
   приложение / пульт — см. раздел 2.1).
3. **Автономность** — добавление режима, в котором робот действует без
   постоянного управления оператором (уточняется: обход препятствий,
   заданная программа движений и т.п. — см. раздел 2.1).
4. **Улучшение моторики** — доработка алгоритмов походки для более плавных
   и устойчивых движений по сравнению с текущей базовой реализацией.
