# Harnet

Робот-паук на ESP32 (4 ноги, 12 серв). Модернизация проекта
[arkadiy-core](https://github.com/VxDxK/arkadiy-core): перенос с Arduino на ESP32.
Полное описание задач - в [docs/technicalTask.md](docs/technicalTask.md).

## Структура репозитория

```
firmware/harnet/        <- скетч Arduino
├── harnet.ino          <- точка входа: setup(), loop(), разбор команд
└── src/                <- остальной код (Arduino IDE собирает src/ автоматически)
    ├── servo_wrap.h/.cpp   <- обёртка над сервой (проценты 0..100, калибровка)
    └── spider.h/.cpp       <- позы и походка
docs/                   <- документация, ТЗ
```


## Команды (Serial)

| Команда | Действие |
|---------|----------|
| `def`   | базовая поза |
| `sp`    | стартовая поза |
| `su`    | встать |
| `go`    | шаг вперёд |
| `ruka`  | поднять ногу («привет») |

## Подключение серв

Питание серв - от отдельного БП 5-6 В (несколько ампер), земля общая с ESP32.

| Серво | GPIO ESP32 | Пин в оригинале (Arduino) |
|------:|-----------:|--------------------------:|
| 0  | 13 | 9  |
| 1  | 14 | 10 |
| 2  | 16 | 12 |
| 3  | 17 | 8  |
| 4  | 18 | 11 |
| 5  | 19 | 13 |
| 6  | 21 | 7  |
| 7  | 22 | 5  |
| 8  | 23 | 3  |
| 9  | 25 | 6  |
| 10 | 26 | 4  |
| 11 | 27 | 2  |

Калибровка углов каждой серво - в `setup()` файла `harnet.ino` (`attach(pin, угол_при_0%, угол_при_100%)`).
